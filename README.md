# Meridian · 需求预测与缺失诊断

一个纯前端、可在浏览器离线运行的需求预测工作台。数据完全由本地确定性合成器生成，所有统计与建模代码都在本仓库内，没有外部服务、CDN 或运行时依赖（React 之外）。

```bash
npm install --cache /tmp/.npm-cache
npm run dev        # http://localhost:5173
npm run build      # tsc --noEmit + vite build
npm run check      # 类型检查 + 33 项模型断言
npm run smoke      # SSR 渲染五个页面，扫描 NaN / undefined 文本
```

## 页面

| 页面 | 回答的问题 |
| --- | --- |
| 预测工作台 `src/pages/Forecast.tsx` | 未来 28 天需求是多少？区间多宽？缺口在哪？补数后重算了哪些分段？ |
| 缺失诊断 `src/pages/Diagnostics.tsx` | 缺失属于随机 / 连续 / 系统性哪一种？证据是什么？推荐哪种策略？ |
| 策略与影响 `src/pages/Strategy.tsx` | 插补 / 降权 / 阻断对误差、区间、预测总量各有什么影响？ |
| 版本与血缘 `src/pages/Versions.tsx` | 这个预测基于哪个训练窗口、哪份特征快照、为什么修订？ |
| 验证与回滚 `src/pages/Validation.tsx` | 回测是否达标？断点与异常值是否成立？回滚后是否一致？ |

## 缺失机制与策略

诊断对每个列做三种检验，组合成机制判定（`src/model/diagnostics.ts`）：

- **游程检验**（Wald–Wolfowitz，chain test）：单日孤点 → 随机缺失（MCAR）。
- **连续游程**：≥3 天的连续缺口，且断点后不复原 → 连续缺失（MAR）。
- **结构性列缺失**：整列在窗口内不可观测（100% 缺失），或缺口贯穿某个渠道 → 系统性缺失，推荐阻断。
- 辅助证据：星期独立性 χ²(6)、缺失指示与需求的点二列相关、断点后是否持续。

每列可独立选择 **插补**（线性插值 × 星期系数）、**降权**（插补行权重 0.32）或 **阻断**（整列/整段剔除）。`src/model/forecast.ts` 的 `buildDesign` 把策略翻译成设计矩阵的权重与列集合。

## 模型

加权岭回归，设计矩阵为：截距 + 趋势 + 趋势² + 6 个星期哑变量 + 3 对年度傅里叶项 + 促销/营销/节假日/自然流量协变量（`src/model/forecast.ts`）。

- 求解走充分统计量 `XᵀX`、`Xᵀy`，不保留逐行矩阵。
- 预测区间由残差 σ 加长程方差膨胀，输出 80% 与 95% 两档。
- 回测为滚动起点（`src/model/backtest.ts`）：7 天起点间隔、14 天步长、210 天训练块（窗口过短时按窗口长度自动收缩），基线为季节朴素。
- 异常值清洗是因果的（只用当日之前的 28 天水平），见 `src/model/preprocess.ts`。
- 断点检测为局部中断时间序列模型（±42 天、星期哑变量 + 台阶项），要求断点后持续且断点前稳定，见 `src/model/breakpoints.ts`。

## 增量重算

训练窗口被切成 28 天分段（`src/model/engine.ts`）。每段缓存充分统计量，键为 `(SKU, 配置, 列策略, 清洗口径, 特征名)` 加该段内容的数值哈希。回补某一天时：

1. 只有包含被改行的分段（及插补边界相邻段）哈希变化；
2. 其余分段直接复用缓存的 `XᵀX` / `Xᵀy`；
3. 求和后重解一次岭回归并刷新区间。

`npm run verify` 断言增量结果与冷启动重建在 1e-6 内一致，且 1 天回补恰好触碰 1 个分段、其余 19 段复用。界面上「最近一次重算」条带会把命中/复用逐段画出，并把增量求解用时与全量重解用时并列，不伪装成全量重建。

## 版本与回滚

`src/model/versions.ts` 定义的版本快照冻结：训练窗口、模型配置、需求与协变量的策略、清洗口径、逐列特征覆盖率与机制、回测指标、数据指纹、重算审计与修订原因。回滚恢复窗口与全部配置，并在版本链上记录来源；已回补的原始数据保留（数据与配置分开回滚）。

## 合成数据

`src/data/dataset.ts` 生成 533 天（2025-06-01 → 2026-11-15）训练与 28 天预测期，3 个 SKU × 3 个渠道口径。缺失按三种机制注入：单日随机丢点、9 月 6–20 日的连续采集中断、以及特定渠道下整列不可观测的促销表。2026-03-16 在精华液上注入了一次水平跃迁，用于验证断点链路。生成过程是确定性的（固定种子），刷新页面结果不变。

## 图表约定

- 类别色只用三档（`--s1/--s2/--s3`），按实体固定分配，不随排名或筛选重排。
- 有序量（缺失天数）用单色相由浅至深的顺序色阶；不出现彩虹色阶，不用值域映射伪装类别。
- 无第二 Y 轴；两个量纲不同就拆成两张图。
- 每张图都有对应的表格视图，图例在三序列以上时始终存在。
- 深色模式是独立挑选的色阶，不是自动反色。
